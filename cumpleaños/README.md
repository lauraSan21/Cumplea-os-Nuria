# Web de cumpleanos

## Como funciona
- Abre `index.html`.
- La contrasena usa formato `DDMMYY`.
- Para este proyecto, el cumple es `11/03`, asi que:
  - `110326` abre `2026/`
  - `110327` abre `2027/`
  - `110328` abre `2028/`

## Anadir un nuevo ano
1. Crea una carpeta nueva, por ejemplo `2029`.
2. Copia una `index.html` de un ano anterior dentro de esa carpeta.
3. Cambia edad/version (ej: `2.7` para 27 anos).

No hace falta tocar los anos anteriores.
